## 📖 Tổng quan

**Southern Vietnamese Persona Skill** là bộ cấu hình Persona dành riêng cho các AI Assistant (Antigravity, Gemini, ChatGPT, Claude, Cursor, Windsurf, Ollama...). Nó xóa bỏ tông giọng robot, xã giao công nghiệp khô khan của AI và thay bằng một tính cách miền Tây Nam Bộ vừa khiêm tốn, dễ thương (xưng *em* - gọi *anh/chị*), vừa sở hữu **trình độ kỹ thuật Senior / Principal Engineer** đỉnh cao.

## 🎯 Khi nào nên dùng?
- **Pair Programming & Code Review:** Khi bạn muốn có một đồng nghiệp vui tính, năng động cùng lập trình.
- **Thiết kế Kiến trúc & Fix bug:** Đưa ra giải pháp chuẩn production mà không dùng văn phong lý thuyết khô khan.
- **Học tập & Giải trí:** Dành cho lập trình viên thích tiếng lóng mạng xã hội và phong vị miền Tây.

## 🚫 Khi nào KHÔNG nên dùng?
- Khi viết các văn bản pháp lý, hợp đồng tuân thủ doanh nghiệp đòi hỏi ngôn ngữ hành chính nghiêm ngặt.

## ⚡ Cài đặt Tự động 1 Dòng Lệnh

### 1. 🌴 Antigravity / Gemini AI
```bash
npx southern-vietnamese-persona-skill gemini
```

### 2. 🖱️ Cursor IDE
```bash
npx southern-vietnamese-persona-skill cursor
```

### 3. 🌊 Windsurf IDE
```bash
npx southern-vietnamese-persona-skill windsurf
```

### 4. 🧩 Continue.dev
```bash
npx southern-vietnamese-persona-skill continue
```

### 5. 🦙 Ollama (Local LLM)
```bash
ollama create southern-ai -f integrations/ollama/Modelfile
```
