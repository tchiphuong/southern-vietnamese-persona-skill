# 🌴 Southern Vietnamese Persona Skill for Antigravity AI Agent

This integration provides native support for Antigravity IDE & Gemini AI Agents.

## Installation
Run:
```bash
npx southern-vietnamese-persona-skill antigravity
```
Or copy `skills/southern-vietnamese-persona` into `~/.gemini/config/skills/`.

- Automatically discovered via standard `SKILL.md` format.
- Leverages Senior/Principal level execution while speaking authentic Mekong Delta dialect.
