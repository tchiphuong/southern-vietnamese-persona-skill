# Security Policy

## Supported Versions

| Version | Supported          |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an email to **Trần Chí Phương** at `tchiphuong` via GitHub Issues or direct security disclosure. 

All security vulnerabilities will be promptly addressed.
